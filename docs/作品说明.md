# 作品说明文档 · 深海学习航线

> 应用名：**深海学习航线**
> 智能体：**汐**（温柔、治愈、年轻的 AI 学习规划师）
> 主题：梦幻海洋 / 深海紫潮 / 极光海域

---

## 一、产品定位

「深海学习航线」是一个将「个人学习目标」转化为「可打卡、可视化、可长期陪伴」的年轻化学习计划应用。它不像传统效率工具那样呈现出冷冰冰的表格与看板，而是把一次完整的学习旅程，比喻成一条在深海中缓缓发光的航线——目标是远方的一座座岛屿，阶段是航行的每一段，每日任务是海面上偶有浮起的气泡。

产品以一个被命名为「汐」的人工智能智能体为核心入口。用户只需用一句自然语言表达想学什么，汐就会像一位耐心的同伴那样，先问清关键信息，再铺出整条航线；之后的每一天，用户可以登岛打卡、点亮进度，看着自己的航线一点一点靠近目标。整体定位面向年轻学习者、学生以及与效率产品产生「社恐」的人群，强调温柔、陪伴与获得感，而非冷冰冰的日程管理。

## 二、核心流程

1. **首次进入即示范**：用户打开应用，系统自动生成一条示例航线（雅思 7 分 · 每天 60 分钟 · 60 天），让新用户立刻看到航线图、今日任务、进度环与打卡徽章的使用方式，显著降低上手门槛。
2. **对话式输入**：用户可以在左侧表单填写「学习目标、当前水平、每日可用分钟、截止日期、偏好」，也可以直接和汐对话。
3. **智能追问**：汐会先检查四个关键字段；只要缺失任一，便以不超过 3 个问题的形式一次问完，不反复打扰。
4. **生成计划**：信息齐全后生成完整计划——2–3 个阶段，每阶段 2 个里程碑，逐日任务（每天总时长不超过用户设定的可支配时间，每周至少安排 1 天休息或轻复习，并按 1/3/7/15 天铺排复习节奏）。
5. **登岛打卡**：用户在「今日任务」中勾选完成项，进度环与连续打卡实时更新；勾满当日任务会有气泡爆开的正向反馈与一句治愈寄语。
6. **生命周期管理**：支持多条航线、切换、删除；随时可通过对话或表单调整输入（例如「我每天只能学 30 分钟」）并自动重算。
7. **导出与分享**：一键导出 Markdown、打印或另存为 PDF、生成适合社交分享的深海军区风格海报。

## 三、视觉与交互设计

### 三色原则与点缀克制
严格遵循「主色三色、点缀二色」：以深海 `#191B41` 为主底、洋流 `#3C3B80` 支撑玻璃卡片与未开始节点、极光 `#9373BC` 承担主按钮与当前节点；仅以水光青 `#5EE7FF`（航线流光、焦点）与薄荷绿 `#7BFFCB`（完成、打卡）作点缀。这样既保证了深海梦幻的统一氛围，又规避了同屏高饱和色过多的杂乱观感。

### 自研视觉语言
不使用任何通用 UI 或图表库，全部组件（玻璃卡片、渐变按钮、胶囊标签、进度环、射线图）均为自研，规避了「传统后台 / 通用 AI 观感」。航线图是纯手写 SVG：岛屿节点沿一条由 Catmull-Rom 平滑插值生成的发光曲线分布，曲线以 `stroke-dashoffset` 实现「逐段绘出」的动效；节点按完成度呈现未开始（半透明洋流蓝）、进行中（极光紫呼吸发光）、完成（薄荷绿微光）三种状态，当前阶段以水光青高亮。

### 动画性能红线
所有动画只使用 `transform`、`opacity` 与 `stroke-dashoffset`，不触碰布局属性，确保滚动流畅。同时提供三层降级：`prefers-reduced-motion` 用户直接关闭装饰动画、低性能设备（核心少 / 内存小 / 省流量 / 窄屏）自动关闭光斑与噪点并降低粒子数、全局 `data-motion` 标记可统一关停所有位移动效。

## 四、技术实现

- **框架**：Next.js 14 App Router + TypeScript；Route Handler 在服务端代理 AI 请求，密钥永不下发浏览器。
- **状态与持久化**：Zustand + `persist` 中间件把航线、打卡与聊天记录存入 `localStorage`，刷新不丢失，支持多计划互不干扰。
- **AI 接入**：通过「Provider 抽象层」设计，原生 `fetch` 调用 OpenAI 兼容 `/chat/completions` 端点；同一套代码可替换通义、智谱或任何自建兼容端点（仅改 `AI_BASE_URL`、`AI_MODEL`）。未配置密钥时自动走确定性本地生成器，保证任何环境都可完整演示。
- **Mock 生成器**：以输入字符串派生的哈希作为随机种子，保证同输入产出一致的计划（确定性），便于测试复现；并内置硬约束——每日时长不超上限、每周含休息或复习、阶段数落在 2–3 之间。这些约束都配有 Vitest 单元断言。
- **导出**：Markdown 由真实计划对象序列化生成；分享海报用 `html-to-image` 直接对真实 DOM 截图，避免重复绘制 Canvas。
- **可访问性**：所有主操作支持键盘（Enter / Space）、`aria-*` 语义、`:focus-visible` 焦点环、对比度达标的中性深色文字配色。

## 五、创新点

1. **「岛屿—航线」学习隐喻**：把抽象的目标管理转化为可被看见、被点亮的空间叙事，情感驱动的正向反馈（打卡后航线发光、任务点亮、气泡爆开）显著提升坚持意愿。
2. **一站式「对话 → 打卡 → 导出」闭环**：从自然语言需求到可执行计划再到持久化与分享，只在一个页面内完成，无需在多工具间跳转。
3. **Mock 优先、AI 可替换**：本地确定性生成器保证离线 / 无密钥也可用，同时保留平滑切换真实模型的接口，兼顾演示稳定与未来可扩展。
4. **克制的视觉体系**：三主色 + 两点缀的显式令牌，配合纯手写 SVG 与玻璃质感，在强个性与专业可用性之间取得平衡。

## 六、可访问性与性能

- 已通过 375 / 768 / 1440 三档宽度验收，无横向滚动，移动端以底部快捷栏增强可达性。
- 支持键盘完整操作与屏幕阅读器语义；`prefers-reduced-motion` 自动降级。
- 动画只触发布局无关属性；低性能设备降低粒子与重效果。

## 七、演示步骤

1. `npm install` → `npm run dev`，打开 http://localhost:3000。
2. 首页自动出现示例航线：查看航线图、今日任务、进度环。
3. 在左侧点「示例计划」填充字段，再点「生成航线」，观察汐完成任务生成与航线更新。
4. 在「今日任务」勾选一项：观察进度环、进度条、打卡反馈。
5. 点「今日打卡」：连续打卡变为 1 天并显示「今日已打卡」。
6. 刷新页面：航线、已勾选任务与连续打卡全部保留。
7. 点击「导出」，选择 Markdown / 打印 / 复制 / 海报体验各导出方式。
8. 不配置任何密钥，全程走本地 Mock，随时可完整演示。

## 八、禁止事项对照

纯黑纯白大面积铺底、霓虹刺眼、同屏高饱和色 > 3、点缀 > 2、遮挡文字、海量粒子卡顿、单一蓝或紫、传统后台观感、超长单文件、虚构密钥——均已通过视觉规范与代码评审规避（详见 `docs/视觉规范.md`）。
