# 深海学习航线 · 视觉规范

> 主题：梦幻海洋 / 深海紫潮 / 极光海域
> 智能体：汐　设计令牌统一在 `src/app/globals.css` 与 `tailwind.config.ts` 中声明。

---

## 1. 色彩系统

### 1.1 主色（严格三色，目标占比一览）

| 令牌 | 色值 | 用途 | 目标占比 |
|---|---|---|---|
| `--midnight`（深海） | `#191B41` | 背景 / 暗部 / 深层面板 | 40–45% |
| `--indigo`（洋流） | `#3C3B80` | 玻璃卡片 / 导航 / 未开始节点 | ~30% |
| `--aurora`（极光） | `#9373BC` | 主按钮 / 进度环 / 当前节点 / 选中态 | 20–25% |

文字色：`--text-1 #F7F4FF`（正文）、`--text-2 #C9C4E6`（次要文字）。
玻璃：`--glass rgba(247,244,255,0.06)`、`--glass-brd rgba(247,244,255,0.14)`。

### 1.2 点缀色（**仅 2 个**，不得再引入）

| 令牌 | 色值 | 语义 |
|---|---|---|
| `--cyan`（水光青） | `#5EE7FF` | 航线流光 / 焦点 / 当前阶段高亮 |
| `--mint`（薄荷绿） | `#7BFFCB` | 完成 / 成功 / 打卡 |

### 1.3 备用（默认不用）

珊瑚粉 `#FF8FA3`、柠檬黄 `#FFE066` 仅作为可选令牌保留，用于错误提示、备用强调。**禁止用于界面主体铺色。**

## 2. 阶段主题映射

`src/lib/theme/tokens.ts` 中 `STAGE_THEME_COLOR`：

- `indigo → #3C3B80`、`aurora → #9373BC`、`cyan → #5EE7FF`、`mint → #7BFFCB`

生成规则：阶段默认在 `indigo / aurora` 之间循环；仅「进行中阶段」临时用 `cyan` 高亮，从而保证任意界面**全局点缀不超 2 个**。

---

## 3. 布局风格

- **Bento 错落网格**：CSS Grid，`md` 两列、`lg` 十二列错落排布（`col-span` 非等宽），不采用等宽三栏。
- **模块可折叠**：卡片内容用 `Collapsible` 收纳，降低信息密度。
- **移动端**：单列横滑卡片(`snap`) + 底部快捷栏；内容区 `pb-28` 保证可上滚避开底部栏。

## 4. 动效清单

> 性能红线：动画**只用 `transform` / `opacity` / `stroke-dashoffset`**，禁止动 `width/height/top/left`。

### 4.1 首屏
- 标题错峰浮现（fade-up / y 位移，0.6–0.7s stagger）
- 光斑漂移（aurora 模糊团 `drift`）
- 气泡上浮（`rise`，固定种子保证 SSR/CSR 一致）
- 波浪分层浮动（三段正弦波 `drift`）
- 航线远景延伸感（背景径向渐变固定）

### 4.2 滚动
- 卡片淡入上浮错峰
- 航线逐段绘制（`stroke-dashoffset`，IntersectionObserver 触发一次）
- 节点依次点亮（呼吸 `breathe`）
- 背景视差（光斑/波浪相对错速）

### 4.3 交互
- 按钮磁吸（`MagneticButton`，仅 transform）
- 点击涟漪（`Ripple`）
- 卡片 3D 倾斜（`GlassCard tilt`，仅 rotateX/rotateY）
- 任务完成气泡爆开（小气泡四散，transform/opacity，600ms）
- 进度数字滚动（rAF/`useSpring`）
- 节点呼吸发光
- 汐思考波浪 / 打字机逐字

### 4.4 转场
- 紫色水波扩散 / 模糊过渡 / 分层飞入（`AnimatePresence` + 折叠高度动画）

### 4.5 性能与无障碍
- `useReducedMotion()`：减少动态时关闭逐段绘制、呼吸、磁吸、3D 倾斜、气泡
- `useLowPerf`：低性能 / 窄屏时关光斑、噪点、3D 倾斜、降粒子数
- 全局 `html[data-motion='off']` + `@media (prefers-reduced-motion: reduce)` 兜底静默动画
- 键盘焦点环（aurora），`:focus-visible`；SVG 节点 `role="button"` + Enter/Space

## 5. 禁止事项

1. **禁止**纯黑、纯白大面积铺底。
2. **禁止**霓虹刺眼 / 颜色过杂；同屏高饱和色 ≤ 3。
3. **禁止**点缀色 > 2（只用 cyan / mint）。
4. **禁止**气泡 / 光斑 / 波浪遮挡文字；文字需可读（可加半透明底垫）。
5. **禁止**海量粒子致卡顿；移动端减粒子。
6. **禁止**通篇单一蓝或单一紫（需三主色合理配比）。
7. **禁止**传统后台观感 / 通用 AI 观感（自研玻璃组件，不引 UI 库）。
8. **禁止**超长难维护单文件（按目录职责拆分）。
9. **禁止**虚构或硬编码 API 密钥。
10. **禁止**动画动 `width/height/top/left`（触发布局）。

## 6. 核心流程图（文字版）

1. 用户打开首页（首次自动生成示例航线）。
2. 用户填写「学习目标 / 当前水平 / 每日时长 / 截止日期」→ 点「生成航线」。
3. 汐先检查关键字段；缺失则追问（最多 3 问），补齐后生成计划。
4. 计划含 2–3 个阶段、每阶段 2 里程碑、逐日任务（每日时长 ≤ 设定值、每周 1 天休息/轻复习）。
5. 航线图以「岛屿节点 + 发光曲线 + 漂浮气泡」呈现；节点状态：未开始(indigo) / 进行中(aurora 呼吸) / 完成(mint)。
6. 用户勾选今日任务 → 进度环 / 进度条 / 连击实时更新。
7. 数据本地持久化；可导出 Markdown、打印 PDF、生成分享海报。
